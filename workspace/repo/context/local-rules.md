# Local Operating Rules

- Do not put repo-specific facts in root entrypoints or `.systems/ai/`.
- Put global repo facts in `workspace/repo/context/`, `workspace/repo/core/repo-intake.md`, `workspace/repo/core/status.md`, and detailed repo memory entries under `workspace/repo/memory/`.
- Keep `workspace/repo/core/context.md` as the router/index for repo context entries.
- Put project-specific execution artifacts in `workspace/projects/<project>/`.
- Put human-facing coordination artifacts in `workspace/humans/<project>/`.
