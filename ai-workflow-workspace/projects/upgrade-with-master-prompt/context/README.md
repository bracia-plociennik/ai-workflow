# Context

## Purpose

This directory stores raw/supporting project context materials for `upgrade-with-master-prompt`.

## Belongs Here

- Raw/supporting inputs for the accepted project context in `../context.md`.
- Raw briefs, specifications, prompt drafts, notes, references, and other project-specific source material before idea validation.
- References that help architecture, planning, specifications, and QA understand project scope.

Before `../context.md` is accepted, this directory can contain raw owner input. `phase-0-idea-validation` must review these materials instead of relying only on chat messages.

Supporting source files in this directory are exempt from `.systems/scripts/check-naming` and may keep source filenames. The accepted project context is not exempt: it must be the canonical `../context.md` file before architecture and later phases.

## Does Not Belong Here

- Repo-wide context; use `AI_WORKFLOW_WORKSPACE_HOME/repo/core/context.md` and `AI_WORKFLOW_WORKSPACE_HOME/repo/context/`.
- Phase evidence; use `quality/`.
- Task specifications; use `specs/`.
- Human-facing summaries; use `AI_WORKFLOW_WORKSPACE_HOME/humans/upgrade-with-master-prompt/`.
