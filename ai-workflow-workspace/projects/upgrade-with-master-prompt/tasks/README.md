# tasks

## Purpose

This directory stores optional detailed task cards for `upgrade-with-master-prompt`.

The canonical task index/router is `AI_WORKFLOW_WORKSPACE_HOME/projects/upgrade-with-master-prompt/tasks.md`.

## Rules

- Task cards are optional supporting artifacts.
- Task cards do not replace phase-3 specifications in `../specs/`.
- Task cards do not replace QA evidence in `../quality/`.
- Task card filenames should use the lowercase task ID slug, for example `ump-core-001-master-prompt-intake.md`.
