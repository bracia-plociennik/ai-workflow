# Compatibility Inspection Facts

Source: current PTO010 Quality and accepted Phase6. Local implementation only.

mapping and one worker/reviewer budget. It verifies actual target HEAD plus
declared file/result hashes and modes, with closing whole-input checks.
Peer accepted/submitted/failed/cancelled labels are review dispositions, not local
approval or authentic termination. Both authority flags remain false.
Known private/key paths, aliases, stale IDs, missing facts and unsafe files reject.
Supplied task labels and occupancy need independent local/backend proof later.
Worktree executor, native dispatch and logical rebase remain unsupported.
No deployed interoperability or speedup is claimed.

System lessons: keep unlike digest populations separate; clear inherited Git
overrides; close every input check after dependent reads; don't turn a fixture
missing an untracked helper into an early commit or skipped validation.
