# Prompt And Skill Efficiency V1

Formal workflow-maintenance project for measuring and reducing unnecessary instruction loading while preserving AI Workflow safety and quality gates.

## Scope

- Baseline behavioral evaluation before tracked source changes.
- Conditional instruction routing, skill trigger precision, completion persistence, and applicable validation cost.
- Post-change paired evaluation and full-current-diff quality review.

## Boundaries

- No production, client, secret, network, or external-effect fixtures.
- No source changes until the baseline evaluation is complete and reviewed.
- High-risk policy edits require owner approval and the formal phase gates.
- Runtime eval output stays in this ignored workspace or approved temporary paths.

## Current Route

Project workspace -> idea validation -> project context/intake -> planning-range -> implementation-range after readiness. Formal autopilot ranges are separate; neither may run phase 8.
