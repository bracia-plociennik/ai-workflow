## Read-only skill plan

**Proposed skill:** `local-cli-command-safety` under `.systems/ai/skills/`. Its job is to review a *specific local CLI command* before it is suggested or run. It would identify the working directory, argument and shell expansion, files or services affected, reversibility, and a safer verification step. It would report uncertainty and route approvals through existing AI Workflow contracts; the skill itself would grant no permission.

**Trigger cases**

- “Is `git clean -fd` safe in this checkout?”
- “Review this migration command before I run it.”
- “Check whether this shell pipeline can delete files or contact an external service.”
- An agent is about to suggest or execute a local command whose effects are unclear.

**Non-trigger cases**

- General coding, planning, documentation, or skill review with no concrete CLI command.
- Reviewing application security code without a command to assess.
- Granting approval to run a command, or replacing the repository’s risk and permissions rules.
- Commands against production or external systems: escalate through the governing contracts rather than treating the skill review as authorization.

**Proposed artifacts:** a compact `SKILL.md` with the trigger description and review procedure, a short `README.md`, and a small set of local positive and negative trigger examples. Add references or scripts only if repeated evaluation shows they are needed.
