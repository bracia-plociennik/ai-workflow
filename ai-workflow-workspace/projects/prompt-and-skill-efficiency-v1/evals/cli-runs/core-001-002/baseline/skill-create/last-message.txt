## Proposed skill

**Name:** `local-cli-safety-review`  
**Future target:** `.systems/ai/skills/local-cli-safety-review/`

The skill would statically review a command or short command sequence in its stated working directory. It would identify likely file changes and external effects, explain uncertainty from variables, globbing, pipes, redirection, command substitution, and invoked scripts, then give an advisory risk assessment and a safer local alternative where useful. It would **not execute the candidate command or grant approval**.

**Proposed trigger description:** “Review the safety and likely effects of proposed local shell or CLI commands before execution, including destructive flags, filesystem scope, indirect scripts, and external effects. Use for explicit command-safety checks; do not activate for routine command execution or general code review.”

| Should trigger | Should not trigger |
| --- | --- |
| “Is `rm -rf ./build` safe to run from this directory?” | “Run the configured unit tests.” |
| “Review this cleanup script before I execute it locally.” | “Fix this Python function.” |
| “What could this `git clean` command delete?” | “Explain what a shell pipe does.” |
| “Check this command for hidden writes or network calls.” | “Review my application code for security issues.” |
| “Suggest a safer form of this proposed migration command.” | “Deploy this service.” Deployment follows its own risk and approval route. |

**Planned artifacts:** a `skill-intake-plan.md` recording scope and trigger cases, a compact canonical `SKILL.md`, and a short `README.md`. Add no scripts or references unless later testing shows a repeated need. The skill must defer to `AGENTS.md`, core risk and permission rules, and phase gates.

**Future evaluation:** Use static local examples covering a safe read, destructive path expansion, shell substitution, an indirect script, and a near-miss routine test request. Check both useful risk explanations and correct non-trigger behavior. Any eventual skill change would need the applicable skill validator and workflow quality review.
