## Screen plan

**Scope and layout.** Show a page title, section navigation, Profile, and Notifications. Profile contains an editable display name and time zone, plus a read-only email address. Notifications contains preference switches. On wide screens, place section navigation beside a single form column with a restrained maximum width. Below roughly 768 px, stack navigation above the form and make fields and actions full width. Check the layout at 320 px, with no horizontal overflow or controls hidden behind a save bar.

**Save behavior.** Load settings with a revision identifier. Keep edits local until the user selects **Save changes**; enable that action only when values have changed and passed client validation. During save, show progress and prevent duplicate submissions. On success, update the saved baseline and announce confirmation. If the user leaves with unsaved changes, use the app’s established confirmation pattern.

| State | Screen behavior and recovery |
| --- | --- |
| Initial loading | Show a stable form skeleton and a labelled loading status; avoid flashing empty fields. |
| Load failure | Replace the form with an error summary and **Try again**. |
| Validation error | Check display name on blur and submit; propose required, 2–80 characters. Put specific errors beside fields, summarize them on submit, and focus the summary. Apply server field errors too. |
| Saving | Keep entered values visible; show progress on the save action. |
| Save failure or offline | Preserve edits, explain that nothing was saved, and offer **Retry** when connectivity returns. |
| Revision conflict | Explain that settings changed elsewhere. Offer **Review latest settings** and require an intentional new save after review; do not silently overwrite either version. |
| Success | Show a brief status message and clear the dirty state. |

Use labelled native controls, visible keyboard focus, an announced status region for load/save results, and errors linked to their fields. A reduced-motion setting should remove nonessential transitions.
