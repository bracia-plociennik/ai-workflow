# External Memory

## Purpose

External Memory stores portable improvement suggestions for AI Workflow itself.

Detailed entries live in `memory/` and are indexed by `external-memory.md`.

External Memory is advisory. It does not override `AGENTS.md`, `.systems/ai/core/`, phase gates, risk model, permissions, Definition of Done, required evidence, or final owner approval.

Do not store product-domain lessons, client-work lessons, frontend/backend/SEO/ads/smart-contract practices, project facts, repo facts, or skill rubrics here. Use `AI_WORKFLOW_WORKSPACE_HOME/system-insights/` for anonymized operating lessons.
