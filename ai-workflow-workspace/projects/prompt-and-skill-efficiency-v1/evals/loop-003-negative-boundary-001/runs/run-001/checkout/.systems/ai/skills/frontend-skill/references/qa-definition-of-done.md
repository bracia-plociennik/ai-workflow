# Frontend QA And Definition Of Done

## Required Review Lenses

- owner intent, accepted plan/spec, scope, and acceptance criteria;
- changed files and route/component boundaries;
- happy path plus loading, empty, blocked, failure, and recovery states;
- keyboard/accessibility behavior and responsive layout;
- data/provenance/integration behavior when applicable;
- regression risk, skipped checks, and residual risk;
- visual evidence at representative viewport sizes when visual output changed.

## Completion

Formal implementation uses `phase-5-quality`. Micro-work uses advisory global quality review. A frontend skill cannot issue formal PASS. Report findings first and disclose what was not tested.
