# Skill Creator

Human-facing summary for the AI Workflow `skill-creator` system skill.

Use this skill when creating, adapting, updating, reviewing, evaluating, or packaging AI Workflow skills.

The full agent contract is in `SKILL.md`.

Bundled resources:

- `agents/`: grading, analysis, and comparison rubrics.
- `references/`: local eval artifact schemas.
- `scripts/`: stdlib-only scaffold, validation, eval, report, packaging, and loop helpers.
- `assets/` and `eval-viewer/`: offline review templates.

This skill is advisory only. It cannot override `AGENTS.md`, `.systems/ai/core/**`, workflow phase files, risk policy, permissions, Definition of Done, evidence requirements, stop conditions, or owner approvals.
