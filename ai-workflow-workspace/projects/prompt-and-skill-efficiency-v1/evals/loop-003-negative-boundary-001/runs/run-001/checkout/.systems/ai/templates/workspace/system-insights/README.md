# System Insights Workspace Templates

Templates used by `.systems/scripts/init-workspace` to create `AI_WORKFLOW_WORKSPACE_HOME/system-insights/`.

## Files

- `README.md` -> template group documentation.
- System Insights runtime files are sourced from `.systems/ai/templates/system-insights/`.

Do not edit these templates from a target repository. Target-specific anonymized insights belong in `AI_WORKFLOW_WORKSPACE_HOME/system-insights/`.
