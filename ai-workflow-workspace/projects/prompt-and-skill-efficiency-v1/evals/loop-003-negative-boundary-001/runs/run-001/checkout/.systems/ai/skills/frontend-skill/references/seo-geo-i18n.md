# SEO, GEO, And I18n

- Define the page purpose, canonical URL behavior, title, description, indexing policy, and structured data when relevant.
- Verify metadata is generated from the real route/data model, not hardcoded demo content.
- Treat `robots`, sitemap, language alternates, locale formatting, timezone, currency, and directionality as explicit concerns.
- Keep headings, link names, visible text, and rendered content aligned for users and crawlers.
- Do not invent rankings, search guarantees, or machine-readable claims without evidence.
