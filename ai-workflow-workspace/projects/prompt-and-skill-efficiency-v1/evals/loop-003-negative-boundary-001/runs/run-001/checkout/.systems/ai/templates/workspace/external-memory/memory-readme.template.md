# External Memory Entries

## Purpose

Store detailed portable External Memory entries for AI Workflow improvement proposals here.

Do not store product-domain lessons, client-work lessons, frontend/backend/SEO/ads/smart-contract practices, project facts, repo facts, or skill rubrics here. Use `AI_WORKFLOW_WORKSPACE_HOME/system-insights/` for anonymized operating lessons.

Use filenames:

```text
YYYY-MM-DD-short-kebab-title.md
```

Every entry must be generalized across repositories and must pass a privacy check before sharing.
