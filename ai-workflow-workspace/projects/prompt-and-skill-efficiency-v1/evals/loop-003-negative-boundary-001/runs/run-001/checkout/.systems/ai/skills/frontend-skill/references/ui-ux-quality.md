# UI And UX Quality

- Start with the user journey, not a component collection.
- Match composition to the product domain and task frequency.
- Keep hierarchy, spacing, typography, contrast, focus, and affordances consistent.
- Avoid nested cards, ornamental gradients, excessive pills, oversized hero type, and decorative elements that compete with the task.
- Make important product state visible: ownership, status, permissions, freshness, pending work, and next action.
- Review responsive behavior at narrow and wide widths; constrain long labels, tables, controls, and dynamic content.
- Use actual product-relevant assets or an explicit empty/placeholder state when real media is unavailable.
