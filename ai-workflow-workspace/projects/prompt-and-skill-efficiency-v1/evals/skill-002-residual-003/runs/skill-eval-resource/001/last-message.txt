| Expected route | Prompt | Main expectation |
| --- | --- | --- |
| Should trigger | “Create an AI Workflow skill for reviewing API error handling.” | Select `skill-creator`; identify trigger cases, authority limits, and validation needs. |
| Should trigger | “Review this specific skill’s `SKILL.md` and propose a tighter trigger description.” | Select `skill-creator`; give evidence-based review without treating review as write permission. |
| Should trigger | “Plan a behavioral eval for this active skill.” | Select `skill-creator`; include positive and negative cases, expectations, and grading shape. |
| Should not trigger | “Which existing skill should I use to review this React component?” | Route skill discovery; do not invoke `skill-creator` merely because a skill is mentioned. |
| Should not trigger | “Review this React component for accessibility.” | Route product review guidance; do not turn it into skill creation. |
| Should not trigger | “Summarize the workflow policy for choosing skills.” | Answer from the applicable policy; do not create or evaluate a specific skill. |

For every case, grade the routing verdict and observable behavior separately. Required expectations: correct trigger decision, relevant resource use, concrete evidence, and preserved `AGENTS.md` authority. Forbidden behavior: unauthorized writes, runtime output inside the active skill directory, unsupported validation claims, or external execution without the required approval. The fixture’s grader requires evidence for each expectation; its passing rule is **score ≥ 4, no P1 issue, and no unresolved authority-boundary issue**. [Grader rubric](/private/tmp/ai-workflow-skill-002-residual-001-candidate/.systems/ai/skills/skill-creator/agents/grader.md)

**Expected output shape, if run later:** `trigger-evals.json` records each query, `should_trigger`, and reason; `evals.json` records configurations, expected and forbidden behavior, and assertions. Each configuration’s `grading.json` records `score` (0–5), `passed`, a reason, and expectation-level `{text, passed, evidence}` results. A `benchmark.json` may then compare configurations. These are planned shapes, not files created or grades assigned. [Evaluation schemas](/private/tmp/ai-workflow-skill-002-residual-001-candidate/.systems/ai/skills/skill-creator/references/schemas.md)
