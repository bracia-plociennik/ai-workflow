# Execution Mode Boundaries
- Type: project-decision
- Status: active
- Source: distillations/phase-6-em-core-001-execution-modes-distillation.md

Interaction mode is independent from work/phase/autopilot mode. The default applies to new work, not legacy approvals. Auto uses covered reversible decisions; Human Coop consults material preferences. Pending choices exclude affected dependencies/resources rather than weakening their gates.

Do not treat readiness inspection or metadata as verification of a real approval, worker isolation or completion. The coordinator verifies actual sources. Missing delivery limits do not create a new 300-minute budget.

Source-only commits change strict QA HEAD identity. Preserve prior assessments unchanged and freshly assess the committed source. Do not restamp old QA or downgrade capture schema to manufacture freshness.
