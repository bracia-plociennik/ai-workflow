## Five Review Requirements

1. Inventory every assertion, not merely test labels; isolation and mutations must establish split equivalence.
2. Current verdict, run identity, baseline, evidence and Gate Decision must refer to the same run; no first/last PASS heuristic.
3. Explicit scope provenance includes staged/unstaged/untracked/deleted/renamed files and separate runtime ownership; requested checks alone cannot prove completeness.
4. Behavioral non-regression precedes instruction promotion; absent authorization or inconclusive evidence defers LV005, not a false project completion.
5. Monotonic high-resolution timings, complete-run manifest and noise-aware comparison; correctness fixes survive a performance regression.
