# External Memory Workspace

This directory is the target-owned workspace for universal AI Workflow improvement notes.

## Layout

- `external-memory.md` - router/index for external memory entries.
- `memory/` - detailed dated external memory entries.

## Ownership

This directory is user-owned in target repositories and is protected by `.systems/scripts/update-from-upstream`.

Do not write workflow improvements into `.systems/ai/` from a target repository. If the workflow needs a change, record the recommendation here and send or promote it through the official `ai-workflow` repository.

External Memory is advisory. It does not override `AGENTS.md`, `.systems/ai/core/`, phase gates, risk model, permissions, Definition of Done, evidence requirements, or final owner approval.
