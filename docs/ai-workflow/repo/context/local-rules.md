# Local Operating Rules

- Do not put repo-specific facts in root entrypoints or `docs/ai-workflow/ai/`.
- Put global repo facts in `docs/ai-workflow/repo/context/`, `docs/ai-workflow/repo/repo-intake.md`, `docs/ai-workflow/repo/status.md`, and detailed repo memory entries under `docs/ai-workflow/repo/memory/`.
- Keep `docs/ai-workflow/repo/context.md` as the router/index for repo context entries.
- Put project-specific execution artifacts in `docs/ai-workflow/projects/<project>/`.
- Put human-facing coordination artifacts in `docs/ai-workflow/humans/<project>/`.
