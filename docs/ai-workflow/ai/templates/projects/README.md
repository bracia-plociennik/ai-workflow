# Project Workspace Templates

Templates for project-local support files, project context, project memory, and project workspace setup.

## Context Templates

- `context-readme.template.md` -> `docs/ai-workflow/projects/<project>/context/README.md`
- `context.template.md` -> `docs/ai-workflow/projects/<project>/context/context.md`

## Memory Templates

- `memory.template.md` -> `docs/ai-workflow/projects/<project>/memory.md`
- `memory-readme.template.md` -> `docs/ai-workflow/projects/<project>/memory/README.md`
- `date-memory-entry.template.md` -> `docs/ai-workflow/projects/<project>/memory/YYYY-MM-DD-short-kebab-title.md`

Do not duplicate workflow phase artifacts here. For phase outputs, use `../workflow/`. For autopilot runtime files, use `../autopilot/`.
