# Project Workspace Templates

Templates for project-local support files, project context, and project workspace setup.

## Context Templates

- `context-readme.template.md` -> `docs/ai-workflow/projects/<project>/context/README.md`
- `context.template.md` -> `docs/ai-workflow/projects/<project>/context/context.md`

Do not duplicate workflow phase artifacts here. For phase outputs, use `../workflow/`. For autopilot runtime files, use `../autopilot/`.
