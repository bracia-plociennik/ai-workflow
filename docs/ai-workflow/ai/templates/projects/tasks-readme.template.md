# tasks

## Purpose

This directory stores optional detailed task cards for `<Project>`.

The canonical task index/router is `docs/ai-workflow/projects/<project>/tasks.md`.

## Rules

- Task cards are optional supporting artifacts.
- Task cards do not replace phase-3 specifications in `../specs/`.
- Task cards do not replace QA evidence in `../quality/`.
- Task card filenames should use the lowercase task ID slug, for example `crm-auth-001-reset-password-flow.md`.
