# Micro-project Templates

Templates for repo-level low-risk micro-projects under `docs/ai-workflow/micro-projects/`.

## Templates

- `micro-project-readme.template.md` -> `docs/ai-workflow/micro-projects/<micro-project>/README.md`
- `micro-project.template.md` -> `docs/ai-workflow/micro-projects/<micro-project>/micro-project.md`
