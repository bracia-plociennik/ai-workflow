# status.md

## Purpose

This file is template-owned. It is not the runtime status for a target repository.

Runtime workflow status belongs in:

```text
docs/ai-workflow/repo/status.md
```

`docs/ai-workflow/ai/status.md` exists only to make the template layout self-describing and to prevent old workflows from treating `docs/ai-workflow/ai` as repo-specific state.

## Template Status

| Field | Value |
| --- | --- |
| `template-role` | `workflow-source` |
| `runtime-status-path` | `docs/ai-workflow/repo/status.md` |
| `repo-specific-data-allowed-here` | `no` |
| `active-project` | `see docs/ai-workflow/repo/status.md` |
| `next-runtime-step` | `see docs/ai-workflow/repo/status.md` |

## Rules

- Do not update this file during normal project execution.
- Do not store active task, active phase, blockers, repo commands, or project state here.
- Update `docs/ai-workflow/repo/status.md` instead.
