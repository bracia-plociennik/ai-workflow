# memory

## Purpose

`docs/ai-workflow/projects/EXAMPLE/memory/` stores detailed example project memory entries.

The router/index is `docs/ai-workflow/projects/EXAMPLE/memory.md`.

This workspace is documentation-only.

## Entry Naming

Create one file per memory entry:

```text
YYYY-MM-DD-short-kebab-title.md
```

Use `docs/ai-workflow/ai/templates/projects/date-memory-entry.template.md` for real project entries.

## Rules

- Do not use EXAMPLE memory as active project state.
- Do not store repo-level, external workflow, or template maintenance memory here.
- Real projects should keep detailed project memory in their own `memory/` directory and update `memory.md` as the router.
