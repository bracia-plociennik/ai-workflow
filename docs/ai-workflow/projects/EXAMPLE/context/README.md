# Context

## Purpose

This directory stores project context artifacts for the EXAMPLE workspace.

## Belongs Here

- Accepted project context.
- Raw briefs, specifications, brand notes, logos, images, PDFs, client guidelines, product notes, and other project-specific source material before idea validation.
- References that help architecture, planning, specifications, and QA understand the project scope.

Before `context.md` is accepted, this directory can contain raw owner/client input. `phase-0-idea-validation` must review these materials instead of relying only on chat messages.

## Does Not Belong Here

- Repo-wide context; use `docs/ai-workflow/repo/context.md`.
- Phase evidence; use `quality/`.
- Task specifications; use `specs/`.
- Human-facing summaries; use `docs/ai-workflow/humans/EXAMPLE/`.
