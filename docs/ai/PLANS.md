# PLANS.md

## Purpose

Working area for complex, multi-step, or high-risk implementation plans before code changes.

## Plan Template

Use the template below for each task or task package plan:

```md
# <task-or-package-name>

## Goal

## Scope

## Out-of-scope

## DoD

## Dependencies

## Risks

## Main Risk

## Start Conditions

## End Conditions

## Readiness Status
- ready / conditional / blocked

## Requires User Decision Before Implementation
- yes / no

## Decisions Needed

## Implementation Steps

## Edge Cases
- handled
- intentionally ignored

## Test Plan
- what we test
- how we test
- pass condition
```

## Rule

Do not use a plan here as a substitute for architecture, project plan, packaging, or task specification artifacts required by workflow.
