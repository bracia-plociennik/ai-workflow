# Project Workspace Templates

Templates for project-local support files, project context, project memory, planning routers, task routers, and project workspace setup.

## Context Templates

- `context-readme.template.md` -> `docs/projects/<project>/context/README.md`
- `context.template.md` -> `docs/projects/<project>/context.md`

## Memory Templates

- `memory.template.md` -> `docs/projects/<project>/memory.md`
- `memory-readme.template.md` -> `docs/projects/<project>/memory/README.md`
- `date-memory-entry.template.md` -> `docs/projects/<project>/memory/YYYY-MM-DD-short-kebab-title.md`

## Planning And Task Templates

- `plans.template.md` -> `docs/projects/<project>/plans.md`
- `tasks.template.md` -> `docs/projects/<project>/tasks.md`
- `tasks-readme.template.md` -> `docs/projects/<project>/tasks/README.md`
- `task-card.template.md` -> `docs/projects/<project>/tasks/<task-id>.md`

## Micro-task Templates

- `micro-tasks.template.md` -> `docs/projects/<project>/micro-tasks.md`
- `micro-tasks-readme.template.md` -> `docs/projects/<project>/micro-tasks/README.md`
- `micro-task.template.md` -> `docs/projects/<project>/micro-tasks/YYYY-MM-DD-short-kebab-title.md`

## Review Templates

- `code-review.template.md` -> `docs/projects/<project>/code-review.md`
- `../reviews/review.template.md` -> `docs/projects/<project>/reviews/YYYY-MM-DD-<task-id>-review.md`

Do not duplicate workflow phase artifacts here. For phase outputs, use `../workflow/`. For autopilot runtime files, use `../autopilot/`.
