# Autopilot Templates

Templates for project-local autopilot and gate artifacts.

Suggested destinations:

- `AUTOPILOT_STATE_TEMPLATE.md` -> `docs/projects/<project>/autopilot/AUTOPILOT_STATE.md`
- `AUTOPILOT_LEDGER_TEMPLATE.md` -> `docs/projects/<project>/autopilot/AUTOPILOT_LEDGER.md`
- `AUTOPILOT_EVENTS_TEMPLATE.md` -> `docs/projects/<project>/autopilot/AUTOPILOT_EVENTS.md`
- `QA_EVIDENCE_TEMPLATE.md` -> `docs/projects/<project>/quality/<phase_task_name>_quality.md`
- `ESCALATION_TEMPLATE.md` -> `docs/projects/<project>/escalations/<task_or_workspace>_escalation_<YYYY-MM-DD>.md`
- `TASK_DECISIONS_TEMPLATE.md` -> `docs/projects/<project>/decisions/<phase_task_name>_decisions.md`

Do not create runtime autopilot state files unless autopilot is active.
