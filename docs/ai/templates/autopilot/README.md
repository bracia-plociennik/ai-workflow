# Autopilot Templates

Templates for project-local autopilot and gate artifacts.

Suggested destinations:

- `autopilot-state.template.md` -> `docs/projects/<project>/autopilot/autopilot-state.md`
- `autopilot-ledger.template.md` -> `docs/projects/<project>/autopilot/autopilot-ledger.md`
- `autopilot-events.template.md` -> `docs/projects/<project>/autopilot/autopilot-events.md`
- `qa-evidence.template.md` -> `docs/projects/<project>/quality/<task-id>-quality.md`
- `escalation.template.md` -> `docs/projects/<project>/escalations/<task-or-workspace>-escalation-<YYYY-MM-DD>.md`
- `task-decisions.template.md` -> `docs/projects/<project>/decisions/<task-id>-decisions.md`

Do not create runtime autopilot state files unless autopilot is active.
