# Repo Runtime Templates

Templates for target-repository runtime artifacts under `docs/repo/`.

Use these when installing or refreshing `ai-workflow` in another repository:

- `context.template.md` -> `docs/repo/core/context.md`
- `context-readme.template.md` -> `docs/repo/context/README.md`
- `context-entry.template.md` -> `docs/repo/context/<entry>.md`
- `legacy.template.md` -> `docs/repo/core/legacy.md`
- `repo-intake.template.md` -> `docs/repo/core/repo-intake.md`
- `status.template.md` -> `docs/repo/core/status.md`
- `memory.template.md` -> `docs/repo/core/memory.md`
- `memory-readme.template.md` -> `docs/repo/memory/README.md`
- `date-memory-entry.template.md` -> `docs/repo/memory/YYYY-MM-DD-short-kebab-title.md`

Keep these templates generic. Do not store repository-specific facts in `docs/ai/templates/repo/`.
