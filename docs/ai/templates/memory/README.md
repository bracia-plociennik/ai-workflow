# memory templates

Templates for AI Workflow template memory entries.

Use these templates for detailed maintenance memory under:

```text
docs/ai/memory/
```

The router/index is:

```text
docs/ai/core/memory.md
```

Do not use these templates for target-repository facts, project memory, external workflow lessons, secrets, client data, or task implementation details.

## Templates

- `date-memory-entry.template.md` -> `docs/ai/memory/YYYY-MM-DD-short-kebab-title.md`
