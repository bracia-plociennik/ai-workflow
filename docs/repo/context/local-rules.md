# Local Operating Rules

- Do not put repo-specific facts in root entrypoints or `docs/ai/`.
- Put global repo facts in `docs/repo/context/`, `docs/repo/core/repo-intake.md`, `docs/repo/core/status.md`, and detailed repo memory entries under `docs/repo/memory/`.
- Keep `docs/repo/core/context.md` as the router/index for repo context entries.
- Put project-specific execution artifacts in `docs/projects/<project>/`.
- Put human-facing coordination artifacts in `docs/humans/<project>/`.
