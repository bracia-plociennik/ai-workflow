# EXAMPLE Autopilot

Autopilot runtime examples. Real runs should recreate these from templates.

## Run Model

Autopilot runtime is organized by run:

```text
autopilot/
  README.md
  runs/
    autopilot-001/
      README.md
      state.md
      ledger.md
      events.md
```

## Current Run

| Field | Value |
| --- | --- |
| Current run | `autopilot-001` |
| Latest run | `autopilot-001` |
| Status | example-only |
| Route | `docs/projects/EXAMPLE/autopilot/runs/autopilot-001/` |

Root-level `autopilot-state.md`, `autopilot-ledger.md`, and `autopilot-events.md` are not canonical in this model.
