# Projects

## Purpose

Logical project runtime workspaces live here: plans, tasks, specs, Quality and Capture.
This is not the AI System `projects/` repository collection. Do not create Git
clones, auxiliary worktrees or scratch runs here. Auxiliary worktrees use the
approved collection `.worktrees/<repository-id>/<work-id>/`; disposable task
files use `.tmp/<work-id>/`. See `.systems/ai/core/workspace-directory-layout.md`.

Create projects through `phase-0-project-workspace` after `phase-0-init` and repo/project intake.

Project paths:

```text
AI_WORKFLOW_WORKSPACE_HOME/projects/<project>/
```

Do not copy `.systems/ai/examples/projects/EXAMPLE` as active facts. Use templates and create project-specific runtime artifacts.
