# Human-Facing Templates

Templates for documents intended for owners, operators, or non-agent readers.

Use these only when the artifact is meant for `workspace/humans/<project>/...`. Workflow execution artifacts belong in `workspace/projects/<project>/...`.

## Templates

- `approval.template.md` - owner approval record.
- `audit.template.md` - human-readable audit report.
- `decision.template.md` - human-facing decision note.
- `plans.template.md` - owner/operator plan with task order, checkboxes, external actions, and next steps.
- `runbook.template.md` - human operational runbook.
- `summary.template.md` - human-readable summary.
