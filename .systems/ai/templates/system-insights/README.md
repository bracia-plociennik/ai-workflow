# system-insights templates

Templates for anonymized, cross-project System Insights.

System Insights belong in:

```text
AI_WORKFLOW_WORKSPACE_HOME/system-insights/
```

Detailed entries belong in:

```text
AI_WORKFLOW_WORKSPACE_HOME/system-insights/insights/
```

Use these templates only for operational lessons that are anonymized and reusable across future projects, clients, skills, or quality reviews.

Do not use System Insights for AI Workflow improvement proposals. Those belong in External Memory.

## Files

- `system-insights-readme.template.md` -> `AI_WORKFLOW_WORKSPACE_HOME/system-insights/README.md`
- `system-insights.template.md` -> `AI_WORKFLOW_WORKSPACE_HOME/system-insights/system-insights.md`
- `insights-readme.template.md` -> `AI_WORKFLOW_WORKSPACE_HOME/system-insights/insights/README.md`
- `system-insight.template.md` -> `AI_WORKFLOW_WORKSPACE_HOME/system-insights/insights/YYYY-MM-DD-short-kebab-title.md`
