# Micro-tasks

This directory stores project-local low-risk micro-task artifacts.

Use it for small, one-off work that is related to this project but does not need full architecture, planning, specification, quality phase, distillation, checkpoint, or autopilot handling.

## Rules

- Keep each micro-task in its own dated Markdown file.
- Record scope, risk, acceptance, changed files, checks/evidence, result, and follow-up/promote decision.
- Do not use micro-tasks for auth, billing, permissions, migrations, secrets, production data, security-sensitive work, external effects, or architectural decisions.
- If risk rises above low, promote the work to the normal workflow.

## Naming

Use:

```text
YYYY-MM-DD-short-kebab-title.md
```
