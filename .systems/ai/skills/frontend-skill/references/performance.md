# Frontend Performance

- Measure before optimizing and tie each optimization to a user journey or budget.
- Keep critical content and interactions on the shortest safe path.
- Audit image dimensions, formats, loading, fonts, JavaScript, hydration, and route transitions.
- Avoid large client bundles, unnecessary hydration, duplicate libraries, and unbounded lists.
- Preserve loading and error states while optimizing; performance work must not hide failures or reduce accessibility.
- Report observed metrics, test conditions, and skipped measurements instead of claiming a universal performance result.
