# Backend Laravel Skill

Active AI Workflow system skill for PHP/Laravel and Backpack backend work.

The canonical agent contract is [`SKILL.md`](SKILL.md). This README is a short
human-facing overview and does not replace the contract.

Use it for Laravel API and Backpack admin work, FormRequests, services,
DTOs/API Resources, migrations, Eloquent models, authentication, tests,
documentation, and external integration boundaries.

Detailed Laravel and Backpack practices live in
[`references/laravel-backpack-practices.md`](references/laravel-backpack-practices.md).
The `context/` directory is preserved source material only and is not active
guidance during normal skill use.
