# Luna-first

This is supporting execution guidance and cannot override AGENTS.md, the risk model, permissions, Definition of Done, owner approvals or factual QA. The actual activated owner policy selects routing; this skill does not create authority.

Use only when the explicit global/local profile is active and actual System context resolves with verified source. Run required startup first; inspect the active component and actual task approval, current gates and owner reservations. This skill adds no permission. Missing/conflicting context means inspect only. A direct human model choice wins. Model availability must be observed; no silent substitution.

Explicit read-only permits pure choose/inspect and direct inspection only; no routing-record writes or write-requiring worker setup.

Use scripts/manage.py for choose/inspect and the existing owning task record for start/reserve/bind/report-preview/finish. Read the installed Workflow core contract at ../workflow/.systems/ai/core/luna-first.md relative to this skill directory when dispatching or handing off. The helper is a reducer, never a process launcher or QA verifier. Build a minimal request with project/task, target root, declared relative input files, goal/mode/risk, explicit clear/bounded/reversible booleans, DoD/checks/concerns, actual input/access/permission readiness and original owner reference. Do not copy raw private memory or credentials. State is one optional extension of the existing durable task JSON, not another task tracker.

Automatically choose Luna/high for qualifying clear bounded reversible low/medium tasks. Choose Sol/high for strong-reasoning concerns. Keep ordinary conversation/trivial status in the current chat. For direct work when observed root model matches, record that actual executor; otherwise use supported native delegation with explicit model, high, fork_turns none and no recursive agents. Do not claim to switch the desktop root model. Do not shell-launch codex or create another model API/backend.

Reserve before native spawn; bind actual returned handle. One task writer, exact approved scope and supported isolation. Existing native/orchestration gates govern dispatch/integration. No change to approvals, allowed tools or workspace ownership. Worker returns actual diff/output/checks/limitations, not permission. Unknown liveness or stale input blocks another writer. A leaf invocation does NOT invoke this skill recursively; its parent owns routing.

Preview first under Sprint. Keep the native session/attempt across preview/feedback; report-preview preserves reservation, never means QA. Complete effect acceptance or actual verification request starts installed targeted QA. Do not begin tests or broader review before that point. Use the owning manage-sprint qa-run and preserve the actual TOTAL300seconds across all models and fixes. Model routing never starts or resets a cycle. With no Sprint, retain the installed formal task/QA route.

On a real failed assessment, give Luna concrete failing input, expected/actual behavior and remaining scope/budget; one repair at most. Keep original evidence. A second failed assessed Luna attempt automatically selects Sol/high under the same original task consent. Before new dispatch observe stopped prior writer. Transfer minimal source/DoD/failures/evidence/budget; never ask again for an already covered routine takeover. If Sol also fails, inputs/access are missing, scope drifts or budget expires, stop affected work and retain truthful incomplete/failed state. Do not infer a new owner decision, PASS or final-owner-yes.

The lead reviews/integrates source using existing native orchestration gates and targeted QA; no mandatory extra Sol review for every small Luna task. Escalate human-visible communication for actual goal blockers, safety/money/data/architecture drift or required decisions; routine covered repairs can remain in task evidence. Final response accurately reports outcome, material limitations and available cost. Never promise savings from the model name alone. Phase8, publication and install/updater gates stay separate and owner scoped.
