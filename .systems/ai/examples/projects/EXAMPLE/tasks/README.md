# tasks

## Purpose

This directory stores optional detailed task cards for the EXAMPLE project.

The canonical task index/router is `.systems/ai/examples/projects/EXAMPLE/tasks.md`.

## Rules

- Task cards are optional supporting artifacts.
- Task cards do not replace phase-3 specifications in `../specs/`.
- Task cards do not replace QA evidence in `../quality/`.
- Task card filenames should use the lowercase task ID slug, for example `ex-docs-001-example-task.md`.
