# reviews

## Purpose

This directory stores project-local review artifacts.

The review checklist/router is `.systems/ai/examples/projects/EXAMPLE/code-review.md`.

## Rules

- Use one file per review.
- Name review files as `YYYY-MM-DD-<task-id>-review.md`.
- Do not use review artifacts as a substitute for QA evidence in `quality/`.
- Do not mark `PASS` unless required evidence exists in the appropriate phase artifact.
